# Configuración privada

No guardar credenciales reales en el repositorio. Usar variables de entorno o archivos de configuración locales excluidos de Git. Crear credenciales y sesiones propias para cada integración. Los marcadores `REPLACE_WITH_YOUR_VALUE` requieren configuración antes de ejecutar.

Esta copia pública se importa con un historial nuevo y sin los archivos privados de los proyectos originales.
